# F1 Race Live Dashboard 🏎️

A web-based Formula 1 race simulation displayed entirely through a dynamic data dashboard. Instead of a graphical track map, this project focuses on real-time telemetry-style data, randomly generated lap times, and unpredictable random events to simulate the progression of a race.

## ✨ Key Features

* **Live Leaderboard:** Real-time updates on driver positions, positional changes, lap progress, and best/last lap times.
* **Randomized Simulation:** Lap times and on-track events are generated randomly, making every simulation unique.
* **Race Events Feed:** A dedicated panel tracking live incidents and race state changes.
* **Simulation Controls:** Full control over the race state (Start, Pause, Resume, Reset) with the ability to accelerate simulation speed up to x8.
* **Dynamic Data:** Real-time UI updates pushed directly from the server.

## 💻 Tech Stack

* **Backend:** C# / ASP.NET Core (MVC)
* **Real-time Communication:** SignalR
* **Database:** SQLite & Entity Framework Core
* **Frontend:** HTML, CSS, JavaScript
